# ПСИР — Частотное разнесение в OFDM через управляемый алиасинг спектральных реплик

## Суть

При преобразовании цифрового сигнала в аналоговую форму возникают спектральные копии за пределами основной зоны Найквиста. Обычно их фильтруют как помеху. Здесь показана возможность целенаправленно использовать их как дополнительные независимые ветви канала связи: два АЦП со сдвигом тактов Δt = Ts/2 дают детерминированную разность фаз π между репликами, что позволяет обратимо разделить их матрицей Адамара и когерентно сложить через MRC. Результат — удвоение порядка частотного разнесения (d ≈ 1 → d ≈ 1.87) без второго ВЧ-тракта.

Если на стороне передачи принципиальная возможность уже закладывается производителями современных ЦАП (генерация сигнала в зоне Найквиста M>1), то на стороне приема алиасинг таких зон с неотфильтрованным сигналом из-за различий в фазах интерферирующих гармоник из разных зон Найквиста (случайность фазовых сдвигов в канале связи) приводит к необходимости поиска метода, при котором прием даст выигрыш за счет дублирования информации на основной гармонике и на гармонике из зоны Найквиста. Поэтому предложен особый метод построения приемника для реализации возможности использования эффекта алиасинга с пользой в системах связи с OFDM-сигналами. 

## Главный файл для запуска

`psir_v2.py` — финальная публикационная версия. Содержит полную символьную верификацию пяти архитектур (базовый приёмник, контроль аппаратуры, предлагаемая схема, теоретический предел, гибрид с MIMO), адаптивный объём выборки до BER ~10⁻⁵, доверительные интервалы Clopper-Pearson и генерацию графика `psid_final_ru.png`.

## Что было раньше и как к этому пришли

**v1 (`psid_wideband_1e-5.py`).** Первая широкополосная модель (ключевая для v1) на N_SUB=64 поднесущих. Ключевое исправление относительно узкополосных прототипов — явная поподнесущая фазовая коррекция exp(−jπ·f/fs) перед матрицей Адамара. Без неё Адамар работает только на f=0; с ней разделение валидно на всём спектре. Три линии сравнения (Baseline / PSID / Ideal MRC), векторизация NumPy, адаптивный объём до 8·10⁵ символов. Используется метод Монте-Карло

**Промежуточные версии (`psid.py`, `psid_rus.py`, `psid_wideband.py`).** Узкополосная эквивалентная модель (одна поднесущая), затем переход к многочастотной. Параллельно отлаживалась физически корректная baseline со случайной фазой алиасинга (деструктивная интерференция), которая даёт d ≈ 1 и служит честной точкой отсчёта.

**v2 (`psir_v2.py`).** Добавлена контрольная линия «два АЦП, одна реплика» — изолирует процессный выигрыш от наличия второго конвертера, чтобы исключить обвинение «выигрыш просто за счёт железа». Добавлен гибридный стенд 2×2 MIMO + ПСИР (подтверждение мультипликативности d_space · d_freq ≈ 3.28). Улучшена статистика: Clopper-Pearson CI вместо точечной оценки, более чистая нормировка мощности ρ₁=ρ₂=0.5 на входе АЦП.
